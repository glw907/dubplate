## Tags with no ruling behind them

Some tags the pass removes name who built or owns a thing and state no decision, so they have no row above:

- `Task N`, the task that built it.
- `pass Nx`, and `3a`, `3b`, `3c`, or `3d` used as an owner, the pass that built or owns it.
- `rung N` and `a rung`, the step of the old build ladder that owns or consumes it.
- `this pass` and `this task`.
- `lane E1`, a work lane.
- `the plan's Global Constraints`, a plan section name.
- The owner's name, where "the owner" is meant.

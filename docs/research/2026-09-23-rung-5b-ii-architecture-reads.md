## internal/auth

PACKAGE: github.com/glw907/dubplate/internal/auth
VERDICT: workmanlike
SUMMARY: internal/auth is dubplate-server's magic-link login. It holds a file-backed store for consumed nonces and revocation epochs, HMAC link and session tokens sharing one signed-value codec, a keyed rate limiter with LRU eviction, a JSON roster with a single write path, a verify-identity seam, and three JSON handlers. The security mechanism is careful throughout. Nonce inserts use O_EXCL and sync the directory. Every record outlives the token that bore it. The base64 is strict and refuses CR and LF, so each credential has exactly one string. The MAC is always checked before any field is read. What costs the package most is its exported surface. It was built bottom-up, and each primitive (MintLink, VerifyLink, MintSession, VerifySession, the cookie builders, the Limiter methods, most sentinels, the Store path helpers) was exported even though its only callers are the handlers and seam in the same package. Outside the package, cmd/dubplate-server uses about fifteen identifiers. The next costs are speculative machinery with no consumer (Subscribe, the Seam interface, normalizeMemberAddress, validID) and comment density about twice the stdlib's, including 52 lines that cite reviews, rulings, rungs, and tasks.

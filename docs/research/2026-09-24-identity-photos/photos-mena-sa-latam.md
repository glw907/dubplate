# Login-page photo research: MENA/Turkey/Iran, South Asia, Latin America

Research for dubplate's rotating login-page photo set. Deep cuts preferred, max one
image per headline artist, live/club/dance-floor/studio/street/record-shop/sound-system
scenes favored over posed portraits. Period 1940s-1980s where possible.

Method: Wikimedia Commons API (categorymembers + search), LOC JSON API, Europeana API,
web search. Each candidate recorded with subject/place/date/photographer/source/license
(quoted, class+jurisdiction)/pixel size/description/fit score 1-5. NC licenses flagged
separately. Provenance risk flagged.

Status: FIRST PASS COMPLETE. Wikimedia Commons only was reached (Europeana, LOC, and the named
institutional archives were not queried — see TODO at bottom). All license classes are as
returned by the Commons API's LicenseShortName field; several "Public domain" entries are
flagged as needing per-file template/jurisdiction verification before shipping, per the brief's
instruction not to infer a license.

**Owner re-weighting (mid-task, from coordinator):** the whole login rotation's core is
reggae/dub/dancehall/ska plus punk/protopunk; the rest spreads out from there. Within this
region's scope that means: Colombian picó and Mexican sonidero sound systems go first, then
Latin American punk and reggae/ska (Brazilian and Argentine punk, late 1970s-80s; Mexican and
Chilean ska), THEN the remaining scenes (Cuban son/mambo, bossa nova/tropicália, chicha, tango,
calypso/steelpan, Fania salsa, and all of MENA/Turkey/Iran/South Asia). Research below is
sequenced to that priority from this point forward; the MENA/Iran/Turkey sweep already done
before the reweighting message is recorded first since it's sunk work.

## PRIORITY 1: Colombian picó and Mexican sonidero sound systems

period (1950s-80s) photography on Commons — a single uploader, **Jdvillalobos**, has built out a
substantial modern documentary set (2019-2024, all "own work," consistent attribution, no
provenance red flags found) that is the best available source. Mexican sonidero material is
richer and includes both modern CC0 street-party documentation and a dedicated set on
**Polymarchs**, a legendary 1970s-founded Mexico City sonidero, from a named uploader crediting
the sonidero's own circle (Djflashback). Champeta-specific searches (the Afro-Colombian genre
picós play) mostly failed on Commons — titles with accented characters returned empty via the
API in this session; worth a manual retry.

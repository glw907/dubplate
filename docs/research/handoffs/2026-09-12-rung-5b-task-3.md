## Decisions the plan did not cover

- **`authEnviron()` fixture helper** (`check_test.go`): a new helper
  alongside `baseEnviron()`/`dropKey()`, returning a fully satisfied
  magic-link environment. Needed because `serve_test.go`'s two
  `productionRegistry()`-backed subtests ("invalid prefix",
  "unparseable bind list") and `TestNewServeCmd_WiredIntoRootCmd` call
  `newServeCmd`/`newRootCmd`, which run `config.Load` before
  `resolveServeConfig`; once the selector became owned-now, those
  environments needed the full magic-link config satisfied or `Load`
  would fail before ever reaching the serve-specific sentinel the test
  checks for. All fixture secret values are visibly synthetic prose
  ("fixture magic link secret, not a real key"), not shaped like real
  keys, so gitleaks stays quiet without a `.gitleaksignore` entry.
- **`newProductionRegistry` vs `productionRegistry` naming**: the plan
  says "productionRegistry calls the shared constructor" — since
  `serve_test.go`'s existing `productionRegistry()` test helper lives
  in the same package as `main.go`, the shared constructor needed a
  distinct name (`newProductionRegistry`) to avoid a duplicate
  declaration; the test helper now delegates to it in one line.
- **`TestDoctorCmd_LiteralSpotCheck`'s second literal**: split into two
  `Execute()` calls — the original `config.NewRegistry()` call for the
  unchanged `DUBPLATE_ADMIN_EMAIL` check, and a new
  `productionRegistry()` + `authEnviron()` call whose output supplies
  the `DUBPLATE_IDENTITY_SOURCE` "ok" literal, since
  `config.NewRegistry()` alone declares no identity source to check
  against.
- `serve_test.go:238`'s `doctorLines(t, reg)` call (via
  `TestDoctorCmd_CarriesServeThresholdsAndNoServeReservedRow`) was left
  on `baseEnviron()` rather than switched to `authEnviron()`: that
  helper is shared by six other call sites, most against
  `config.NewRegistry()` (no auth family declared), and the test in
  question asserts nothing about the identity-source row, so the
  change would have been surface area with no test behind it.

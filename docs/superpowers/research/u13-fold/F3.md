File: /var/home/glw907/Projects/dubplate/internal/reject/reject.go:78

ReasonBadExtension's NextStep is "Convert it to FLAC and upload it again." That instruction is shared verbatim with the uploader page (preflight.ts mirrors it as `next_step`) and with the rejection email. Add the no-FLAC-available escape the email already gives if the string has room: the admin can add it by hand. Update preflight.ts's badExtensionReason.next_step verbatim and the reject golden tests.

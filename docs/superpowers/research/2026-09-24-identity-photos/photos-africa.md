# African Music Scenes — Photo Research for dubplate Login Rotation

Method: Wikimedia Commons API (categorymembers + search), Library of Congress
JSON API, Europeana API, targeted web search. License verified from source
metadata, never inferred. Uploader-vs-photographer mismatches flagged as
provenance risk. Images under 1000px long edge capped at fit score 2.

Status: IN PROGRESS — appended after each scene.

## Cross-cutting: Library of Congress (loc.gov / World Digital Library) and
Europeana API sweeps

Ran one representative query against each API rather than one per scene
(time-boxed): LOC `q=african+music+festival` scoped to World Digital
Library, and Europeana `query=african+music+band&reusability=open`.

**Both came back empty of any African-music-scene material.** LOC surfaced
only unrelated 19th/early-20th-century travel-narrative texts and one
Venezuelan folk-dance photo. Europeana surfaced only unrelated European/
Swedish ethnographic items (a 1607 equestrian event, an early-20th-century
mask artifact, a missionary diary). Neither API's general-purpose query
found the ETH-Bibliothek/Bundesarchiv/Anefo material this brief expects —
that material is reachable through Commons (where it already surfaced
incidentally: the Anefo-credited Miriam Makeba and Tony Allen/
Noord-Hollands Archief finds above came through Commons search, not a
direct LOC/Europeana hit).

**This is a real gap in this pass, not a finding of absence**: neither API
was walked scene-by-scene (e.g. LOC queries per named artist, Europeana
`qf=DATA_PROVIDER:"Bundesarchiv"` filters) due to time. A follow-up pass
should retry LOC and Europeana per-artist rather than with one broad
genre query, and should walk Commons categories directly for
`Category:Bundesarchiv`, `Category:ETH-Bibliothek_Bildarchiv`, and
`Category:Nationaal_Archief` cross-referenced against each named African
artist/place, which was not done here.

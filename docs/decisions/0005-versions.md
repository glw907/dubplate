# 5. Versions

## Status

Accepted

## Context

Geoff set the version numbers on 2026-09-25 (commit `3b0c138`) and re-planned them on 2026-10-05,
when the box swap and the earlier pre-release were dropped.

## Decision

The first launch is 0.8.0, on the built-in streamer, with no earlier pre-release and no box swap.
0.9 adds the paired local client. 1.0 adds polish and the remaining features, the format ladder
among them. A version names what a member can do with it.

## Consequences

A document older than this ruling keeps its numbers and stays as written. BACKLOG's "Milestones to
0.8" holds the build order to the first launch.
